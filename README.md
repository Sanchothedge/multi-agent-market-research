# Multi-Agent Market Research

A Python implementation of the multi-agent market research workflow, rebuilt as a local CLI that can run either with live You.com/OpenAI APIs or in offline dry-run mode when external services are unavailable.

## What it does

Given a target company profile, the app:

1. Finds candidate competitors using You.com search evidence.
2. Selects up to three competitive matches using an LLM.
3. Researches each competitor across key categories: products, pricing, features, target customers, positioning, reviews, leadership/funding/news, and recent news.
4. Validates evidence quality and retries incomplete results.
5. Builds a structured report and emits a real .docx report file.
6. Keeps JSON artifacts in `runs/<run_id>/` so each run is inspectable.

## Repository contents

- `main.py` — CLI entry point
- `src/` — pipeline logic, model types, search client, validation, report generation, and storage
- `tests/` — smoke tests, including dry-run verification
- `preview.html` — lightweight local HTML preview page
- `runs/` — local outputs generated by the app

## Setup

```bash
cd "Mastering Agentic AI/week 3/Multiagent-Market Research/market-research-agent"
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
cp .env.example .env
```

Then add your API keys to `.env`:

```env
YOU_API_KEY=your_you_com_api_key
OPENAI_API_KEY=your_openai_key
OPENAI_MODEL=gpt-4o-mini
```

## Run live

```bash
python main.py \
  --company-name "Acme" \
  --company-website "https://acme.com" \
  --industry "B2B software" \
  --target-market "Mid-market SaaS" \
  --country "US" \
  --lookback-days 30
```

## Run dry-run mode

Use this when You.com or OpenAI is unavailable, the account is blocked, or you just want a local smoke test:

```bash
python main.py --dry-run \
  --company-name "Acme" \
  --company-website "https://acme.com" \
  --industry "B2B software" \
  --target-market "Mid-market SaaS" \
  --country "US" \
  --lookback-days 30
```

This writes a local .docx report and keeps the pipeline functional without external API calls.

## Output

Each run writes artifacts under:

```text
runs/<run_id>/
```

including:

- `run.json`
- `competitors.json`
- `evidence.json`
- `report.docx`

## Preview

A local HTML preview file is also included:

```text
preview.html
```

Open it in a browser, or run a local file server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000/preview.html
```

## Notes

- The project includes a working dry-run fallback for environments with billing or auth issues.
- The live You.com endpoint returns `402 Payment Required` when the account is not authorized to use it; the dry-run path avoids that dependency for development and smoke testing.
- The repository intentionally does not commit real API keys.
